## 🎯 Задача
Оптимизировать систему памяти для максимальной эффективности и минимального потребления токенов.

## 🔍 Анализ проблемы

### До оптимизации:
- **27 beads** созданы, но не используются эффективно
- **96K токенов** на сессию (чтение множества файлов)
- **Дублирование функций** между beads и памятью
- **Сложная навигация** по историческим данным

### Корневые проблемы:
1. **Beads слишком детальные** - каждый bead 2-5K токенов
2. **Нет иерархии** - все файлы равнозначны
3. **Отсутствует быстрый доступ** к частым задачам
4. **Избыточная информация** в документации

## 💡 Решение: Гибридная система

### 📊 Новая иерархия памяти:

#### 1️⃣ **QUICK_REFERENCE.md** (0.5K токенов)
- ТОП-10 файлов проекта
- Частые задачи с готовыми решениями  
- Горячие клавиши поиска
- One-liner команды

#### 2️⃣ **CODEINDEX.md** (2K токенов)
- Полная карта всех модулей
- Авто-обновление через `npm run index`
- Поиск по названию без чтения кода

#### 3️⃣ **DECISIONS.md** (1K токенов)
- Архитектурные правила
- Что НЕЛЬЗЯ менять
- Причины решений

#### 4️⃣ **CURRENT_TASK.md** (0.2K токенов)
- Контекст текущей сессии
- Следующие шаги

#### 5️⃣ **Beads** (только критичные)
- Только изменения > 500 строк
- Миграции БД
- Рефакторинг архитектуры

## 📋 Новые правила работы

### Алгоритм работы AI:
1. **QUICK_REFERENCE.md** → готовое решение?
2. **CODEINDEX.md** → найти модуль
3. **DECISIONS.md** → проверить правила
4. **CURRENT_TASK.md** → обновить контекст

### Когда создавать beads:
- ✅ Изменения > 500 строк кода
- ✅ Миграция БД или данных  
- ✅ Полный рефакторинг модуля
- ✅ Новый внешний сервис

### Когда НЕ создавать beads:
- ❌ Правки < 100 строк
- ❌ Bug fixes < 50 строк
- ❌ Добавление 1-2 функций
- ❌ Изменения UI/стилей
