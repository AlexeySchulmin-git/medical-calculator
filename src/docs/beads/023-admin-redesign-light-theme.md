## Что сделано:
- Вынесен CSS в отдельный файл `public/admin.css` (решает проблему лимита токенов при редактировании)
- Полная смена темы: тёмная (#0f172a) → светлая (#f0f2f5 фон, #fff карточки)
- Обновлены CSS-переменные: новая палитра с `--accent-light`, `--ok-light`, `--err-light`, `--warn-light`
- Логин: новый лейаут с иконкой и подзаголовком, скруглённая карточка с тенью
- Сайдбар: иконка бренда, секции навигации («Основное» / «Настройки»), активный пункт — синий фон
- Статистика: иконки в заголовках карточек (📋🔵🟡🟢)
- Бейджи статусов: pill-стиль с цветной точкой вместо тёмных прямоугольников
- Таблица: светлый заголовок (`surface2`), hover строк `#fafbfc`
- Кнопки: обновлены стили, добавлен `btn-danger`, `btn-full`
- Модальное окно: `backdrop-filter: blur`, тень, кнопка закрытия с фоном
- Info-box: синий светлый фон вместо тёмно-синего
- Убраны все inline-стили с переменными старой тёмной темы

## Влияние:
- Визуально современный, профессиональный интерфейс
- CSS легко редактировать и расширять без ограничений по токенам
- Следующие шаги: добавить страницу системы лояльности
