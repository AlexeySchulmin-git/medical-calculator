## Что сделано:

### 1. Убрана зелёная рамка у необязательных полей
- Поля спуск/подъём с этажей, сопровождение — больше не подсвечиваются зелёным при изменении

### 2. Убрана валидация веса
- Поле "Вес пациента" стало необязательным, убраны min/max ограничения и ошибки

### 3. Диагноз → выпадающий список (обязательный)
- Варианты: Инсульт, Перелом шейки бедра, Онкология, Инфаркт, Свой вариант
- При выборе "Свой вариант" появляется текстовое поле
- Валидация при отправке: нельзя отправить без выбора

### 4. Убран блок "Количество врачей" у мед. сопровождения
- Чекбокс остался, подсказка осталась, выпадающий список кол-ва врачей удалён

### 5. Исправлена логика сопровождения
- Было: +500 за каждого сопровождающего
- Стало: +500 (no_escort_fee) только при выборе "Без сопровождения"
- По умолчанию: 1 человек (без надбавки)
- Значение надбавки берётся из настроек админки (no_escort_fee)

## Влияние:
- Виджет стал проще и понятнее для пользователя
- Расчёт цены теперь корректно отражает логику бизнеса
- Фиксированная цена для Раменского (4500 ₽) теперь показывается правильно
