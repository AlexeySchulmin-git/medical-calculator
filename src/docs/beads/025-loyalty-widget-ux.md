## Что сделано:

### Виджет (widget-calculator.js)
- Блок `#loyaltyBlock` после поля телефона (скрыт по умолчанию)
- При вводе 11 цифр телефона → запрос `/api/loyalty/balance` → показ блока
- **Если баланс > 0**: зелёный блок «У вас X баллов», чекбокс «Списать X ₽ бонусами»
- **Если баланс = 0**: синий блок «За этот заказ начислится ~X баллов»
- При изменении цены (showResult) → блок лояльности перерисовывается с актуальной суммой
- При восстановлении формы из localStorage → автозагрузка баланса через 500мс
- `bonus_used` передаётся в тело заказа при отправке
- Расширенный экран успеха: номер заявки + бейдж с начисленными/списанными баллами

### Сервер (medical-api-server.cjs)
- `bonus_used` из тела заказа → `finalPrice = max(0, price - bonus_used)`
- Списание: `UPDATE customers SET bonus_balance = GREATEST(0, balance - bonus_used)`
- Начисление: % от `finalPrice` (не от полной цены)
- Если первый заказ без баллов → создаём запись клиента (статистика)
- Ответ содержит `bonus_earned` и `bonus_used`

## Флоу клиента:
1. Вводит телефон → видит баланс или прогноз начисления
2. Отмечает «Списать бонусы» (если есть) → цена снижается
3. Отправляет заявку → экран успеха с информацией о баллах
4. Следующий визит: localStorage → автозагрузка баланса
