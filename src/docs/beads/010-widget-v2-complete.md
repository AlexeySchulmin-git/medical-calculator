## Технические решения

### Почему honeypot вместо только autocomplete="off"
Chrome намеренно игнорирует `autocomplete="off"` для полей типа text/email/tel. Скрытые поля `type="text"` + `type="password"` в начале формы перехватывают автозаполнение браузера.

### Почему select вместо number для этажей
Ограничение 1–10 встроено в UI, исключает невалидный ввод без дополнительной валидации. Значение 0 = "не нужно".
