# План реализации медицинского калькулятора

## Обзор проекта
Универсальный виджет медицинского калькулятора (Shadow DOM, чистый JS) с бэкендом на Express (`medical-api-server.cjs`), MySQL и интеграциями DaData + GraphHopper.

---

## Выполнено (v2.0 — текущее состояние)

### Инфраструктура
- [x] Next.js проект (TypeScript) — фронтенд оболочка
- [x] Express API сервер (`medical-api-server.cjs`, порт 3003) — основной бэкенд
- [x] MySQL (XAMPP): таблицы `clients`, `orders`, `address_cache`
- [x] `.env.local`: DB, SMTP, DaData, GraphHopper, APP_URL

### Виджет (`public/widget-calculator.js`)
- [x] Shadow DOM, изоляция стилей
- [x] Одноэтапная форма (все поля на одном экране)
- [x] DaData: подсказки адресов с debounce 300ms
- [x] GraphHopper API: расчёт расстояния по дорогам (fallback: OSRM → Haversine)
- [x] Маска телефона `+7 (___) ___-__-__`
- [x] Скриптовая валидация (без браузерных подсказок): blur + submit
- [x] Зелёная граница при валидном заполнении (все поля кроме чекбоксов)
- [x] Крестики очистки для текстовых полей
- [x] autocomplete отключён (honeypot + `autocomplete="off"`)

### Поля формы
- [x] Откуда / Куда (с подсказками DaData и координатами)
- [x] Вес пациента (30–180 кг)
- [x] Спуск без лифта / Подъём без лифта (select 1–10 этаж)
- [x] Сопровождение родственники (select: 1 чел / 2 чел / без)
- [x] Туда-обратно (с подсказкой стоимости ожидания 500 руб/30 мин)
- [x] Медицинское сопровождение + кол-во врачей (1/2)
- [x] Нужен кислород
- [x] Телефон, Email, Диагноз, Комментарий
- [x] Согласие на обработку персональных данных

### Расчёт стоимости
- [x] База + км + вес + спуск/подъём по этажам + эскорт + кислород + туда-обратно
- [x] Пересчёт при изменении любой опции
- [x] Отображение выбранных опций тегами (без сумм)
- [x] Примечание: "без учёта платных дорог и выбранных опций. Не является публичной офертой."

### API (`medical-api-server.cjs`)
- [x] `POST /api/orders` — сохранение заявки в MySQL
- [x] `POST /api/dadata/suggest` — подсказки адресов (реальный DaData)
- [x] `POST /api/dadata/distance` — расстояние (GraphHopper → OSRM → Haversine)
- [x] Детальное логирование ошибок
- [x] API-key авторизация (`X-API-Key`)
