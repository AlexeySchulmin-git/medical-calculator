# 🧠 Оптимизированная система памяти

## 🎯 ПРИНЦИП: Минимум токенов, максимум пользы

### 📋 Иерархия памяти (от быстрого к детальному)

#### 1️⃣ **QUICK_REFERENCE.md** (0.5K токенов)
- **ТОП-10 файлов** проекта
- **Частые задачи** с готовыми решениями
- **Горячие клавиши** поиска
- **One-liner команды**

#### 2️⃣ **CODEINDEX.md** (2K токенов)
- **Полная карта** всех модулей
- **Поиск по названию** без чтения кода
- **Авто-обновление** через `npm run index`

#### 3️⃣ **DECISIONS.md** (1K токенов)
- **Архитектурные правила**
- **Что НЕЛЬЗЯ менять**
- **Причины решений**

#### 4️⃣ **CURRENT_TASK.md** (0.2K токенов)
- **Контекст текущей сессии**
- **Следующие шаги**

#### 5️⃣ **Beads** (только по необходимости)
- **Критичные изменения** (> 500 строк кода)
- **Миграции БД**
- **Рефакторинг архитектуры**

## 🚫 ПРАВИЛО Beads

### Создавать bead ТОЛЬКО если:
- **Изменение > 500 строк** кода
- **Миграция БД** или данных
- **Полный рефакторинг** модуля
- **Новый внешний сервис** интеграция

### НЕ создавать bead если:
- **Правка < 100 строк**
- **Bug fix < 50 строк**
- **Добавление 1-2 функций**
- **Изменение UI/стилей**
