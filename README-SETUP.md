# Медицинский калькулятор - инструкция по настройке и тестированию

## 🚀 Быстрый старт

### 1. Настройка базы данных

1. Запустите XAMPP (Apache + MySQL)
2. Откройте http://localhost/phpmyadmin
3. Выполните SQL из файла `test-client.sql` для создания тестового клиента

### 2. Настройка переменных окружения

Создайте/обновите файл `.env.local`:

```env
# База данных
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASS=
DB_NAME=medical_calculator

# DaData API (получите на https://dadata.ru)
DADATA_API_KEY=ваш_ключ_dadata

# Email настройки (Gmail пример)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@gmail.com
SMTP_PASS=your_app_password
MANAGER_EMAIL=manager@yourcompany.ru

# Приложение
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### 3. Запуск проекта

```bash
npm run dev
```

Проект будет доступен по адресу: http://localhost:3000

## 🧪 Тестирование

### Тестовая страница

Откройте: http://localhost:3000/test.html

На тестовой странице можно:
- Проверить загрузку виджета
- Протестировать API конфигурации
- Отправить тестовый email
- Проверить подсказки адресов

### API ключ для тестов

```
test-api-key-12345
```

## 🔧 Основные компоненты

### API эндпоинты

- `GET /api/widget/config` - получение конфигурации виджета
- `POST /api/dadata/suggest` - подсказки адресов
- `POST /api/dadata/distance` - расчёт расстояния
- `POST /api/orders` - создание заявки
- `POST /api/notifications/email/test` - тест email

### Виджет

Собранный виджет находится в `public/widget.js`
Для вставки на сайт:

```html
<script src="https://ваш-домен/widget.js" data-key="API_КЛЮЕНТА"></script>
```

### База данных

Основные таблицы:
- `clients` - клиенты (компании использующие виджет)
- `orders` - заявки на перевозку
- `address_cache` - кэш адресов DaData

## 🐛 Поиск и исправление ошибок

### Частые проблемы:

1. **Виджет не загружается**
   - Проверьте консоль браузера
   - Убедитесь что API ключ правильный
   - Проверьте что Next.js сервер запущен

2. **Email не отправляется**
   - Проверьте настройки SMTP в `.env.local`
   - Для Gmail используйте App Password
   - Протестируйте через `/api/notifications/email/test`

3. **DaData не работает**
   - Проверьте API ключ в `.env.local`
   - Убедитесь что у вас есть лимиты запросов

4. **База данных**
   - Проверьте что MySQL запущен
   - Убедитесь что база `medical_calculator` создана
   - Выполните SQL из `test-client.sql`
